Как настроить

  1. 1Нажмите «Установить расширение». Если браузер открыл пустую вкладку, скопируйте адрес ниже и вставьте его в адресную строку браузера.
  2. 2В браузере включите режим разработчика, нажмите «Загрузить распакованное расширение» и выберите открытую папку.
  3. 3Перезапустите браузер, затем нажмите «Проверить подключение».

Установщик работает без .NET Runtime и прав администратора. Браузер требует вручную подтвердить загрузку расширения.
