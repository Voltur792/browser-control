# Расширение Astra Browser Control

Расширение подключает выбранный браузер к локальному плагину Astra. Браузер требует вручную подтвердить загрузку распакованного расширения.

## Установка в Яндекс Браузер

1. Установите плагин Astra и нажмите **«Установить расширение»** на вкладке «Браузер» или запустите `install-extension.cmd` в корне папки плагина.
2. Установщик откроет страницу расширений и папку `%LOCALAPPDATA%\AstraBrowserControl\browser-extension`. Включите **Режим разработчика**, нажмите **«Загрузить распакованное расширение»** и выберите эту папку.
3. Перезапустите браузер и нажмите в Astra **«Проверить подключение»**.

Для Chrome и Edge шаги те же: откройте страницу управления расширениями, включите режим разработчика и выберите установленную папку. Скрипт добавляет запись Native Messaging для Chrome, Яндекс Браузера и Edge в профиль текущего пользователя Windows.

`install-extension.cmd` запускает PowerShell только для этого процесса, не меняя общую политику Windows. Разработчикам для повторной сборки host нужен .NET SDK 9; пользователям готового пакета .NET Runtime не нужен.

## Удаление Native Messaging Host

В PowerShell из корня плагина выполните `./install-extension.ps1 -Remove`. Затем удалите расширение со страницы управления расширениями браузера.

## Разрешения расширения

`nativeMessaging` связывает расширение с локальным компонентом; `tabs` и `scripting` нужны для вкладок и действий на странице; доступ к HTTP/HTTPS сайтам нужен только в расширенном режиме. Список вкладок включает все окна одного профиля браузера, но полные пути, параметры и фрагменты адресов не передаются в Astra. Чтение страницы и действия выполняются только по команде Astra. Поля ввода скрыты, страницы с видимыми полями паролей, кодов или карт блокируются, результаты фильтруются до отправки. Расширение не отправляет историю вкладок или текст страниц в сеть.

После обновления плагина снова запустите установщик, затем откройте страницу расширений браузера и нажмите **«Обновить»** на карточке Astra Browser Control. Для новых инструментов плагина перезапустите Astra или выключите и снова включите плагин.

При сохранении контекста страниц фильтр скрывает поля ввода, типичные коды, карты и строки с признаками секретов. Произвольный секрет, напечатанный как обычный текст без признаков, нельзя гарантированно отличить от обычного содержимого страницы.

Примеры команд: **«Покажи вкладки во всех окнах»**, **«Переключись на вкладку 20»**, **«Закрой вкладку 20»**, **«Закрой вкладки 20 и 21»**, **«Закрой текущую вкладку»**. Нумерация сквозная по окнам из свежего списка; несколько номеров закрываются одним действием, чтобы индексы не сдвинулись между закрытиями.

## Если соединения нет

- Убедитесь, что плагин загружен и Astra работает.
- Проверьте, что в `%LOCALAPPDATA%\AstraBrowserControl\native-host` установлен файл `BrowserControlNativeHost-*.exe`.
- Откройте всплывающее окно расширения и нажмите **«Проверить подключение»**.
- После установки Native Messaging Host перезапустите браузер.
- Проверьте в Astra статус на вкладке **«Браузер»**. В логах плагина находится диагностика запуска локального моста.
